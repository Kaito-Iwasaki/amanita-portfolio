# Kaito-Iwasaki Portfolio

赤・白・丸い形とベニテングダケをモチーフにした静的ポートフォリオです。

## 構成

- dist/index.html: 自己紹介、スキル、作品、連絡先
- dist/style.css: スマートフォン対応デザイン
- dist/script.js: Discordユーザー名のコピー
- dist/mushroom.svg: オリジナルアイコン
- dist/images/project-placeholder.png: 3作品共通の仮画像

ビルドや外部ライブラリは不要です。dist/index.htmlをブラウザーで開けます。クリップボード操作にはHTTPSまたはlocalhostが必要です。

## 掲載内容

GitHubの公開ソースから確認できたC++、DirectX 9、Visual Studioを掲載。経験年数や個人の担当範囲は未確認のため記載していません。作品画像には、ユーザー指定の3Dキャラクター画像を3件共通の仮画像として使用しています。

## 更新

紹介文、作品、連絡先はdist/index.html、デザインはdist/style.cssを編集してください。

## GitHub Pages

Settings → Pages → SourceをGitHub Actionsに設定します。同梱ワークフローはmainへのpushまたはActions画面のRun workflowでdistを公開します。
